# Plan: vikunja-mcp v0.0.1

## Resumen

MCP server que conecta un agente AI (OpenCode) con Vikunja vía API REST, permitiendo CRUD completo de proyectos, tareas, labels, notificaciones y más. Soporte Linux + macOS. Python ≥ 3.11 con venv en `~/.vikunja-mcp/env/`.

## Estructura del proyecto

```
vikunja-mcp/
├── install.sh              # Instalador + registrador MCP en opencode.json
├── uninstall.sh            # Desinstalador completo
├── README.md
├── CHANGELOG.md
├── INSTALL.md
├── LICENSE                 # GPLv3
├── AGENTS.md
├── AUTHORS                 # FErArg (owner) + AI contributors
├── mcp/
│   ├── run_mcp.sh          # Launcher: detecta SO, activa venv, lanza server.py
│   └── vikunja_mcp/
│       ├── __init__.py
│       ├── server.py       # MCP server (FastMCP)
│       ├── api.py          # Cliente Vikunja API (requests, Bearer auth)
│       ├── config.py       # Lee ~/.vikunja-mcp/config.json
│       └── tools.py       # Definición de todas las tools MCP
├── test/
│   ├── __init__.py
│   ├── test_api.py         # Tests unitarios cliente API (mock HTTP)
│   ├── test_server.py      # Tests unitarios server.py
│   └── test_install.py     # Tests del installer
└── docs/
    └── api-notes.md
```

## Fase 3 — Launcher script mcp/run_mcp.sh

- Detecta SO (Linux/macOS)
- Verifica Python >= 3.11
- Activa venv en ~/.vikunja-mcp/env/
- Lanza server.py con config.json como argumento

## Fase 4 — Instalador install.sh

1. Detectar SO (Linux/macOS) → error si no soportado
2. Verificar Python >= 3.11 → error si no
3. Crear ~/.vikunja-mcp/ y ~/.vikunja-mcp/env/
4. python3 -m venv ~/.vikunja-mcp/env/
5. pip install -r requirements.txt
6. Solicitar URL de Vikunja (prompt interactivo)
7. Solicitar token API (prompt interactivo)
8. Escribir ~/.vikunja-mcp/config.json
9. Generar MCP config entry para opencode.json
10. Backup de ~/.config/opencode/opencode.json → opencode.json.bak
11. Merge: insertar entrada "vikunja-mcp" en el array "mcp" existente
12. Test de conexión contra la API Vikunja
13. Mensaje de éxito

## Fase 5 — Desinstalador uninstall.sh

1. Solicitar confirmación ("yes" para proceder)
2. Eliminar ~/.vikunja-mcp/ completo (rm -rf)
3. En opencode.json: extraer entrada "vikunja-mcp" del array "mcp"
4. Preservar el resto del archivo intacto
5. Mensaje de desinstalación completada

## Notas técnicas clave

- Python 3.11 mínimo (macOS tiene 3.9; installer detecta y aborta)
- Venv location: ~/.vikunja-mcp/env/
- Launcher: ~/.vikunja-mcp/mcp/run_mcp.sh
- Config location: ~/.vikunja-mcp/config.json (pasado como argumento)
- Auth: Bearer token en header Authorization: Token TOKEN
- OpenCode MCP config en ~/.config/opencode/opencode.json bajo "mcp"
- Merge strategy: leer JSON existente, añadir/actualizar solo entrada "vikunja-mcp"
